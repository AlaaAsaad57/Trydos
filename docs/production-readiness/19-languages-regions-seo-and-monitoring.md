# Languages, regions, SEO and monitoring — Production readiness

**Status:** 🟡 Ready with conditions
**In one line:** Locale routing, translations and error reporting work. Before launch, ops must set the site address and indexing flags, and Frontend must fix a few SEO and analytics defects.
**Checked:** branch `development`, commit `6a0265a1`, 2026-10-20 — from the code only.

## What this section is
- The shared shell on every page: header with logo and user area, the region picker, language and right-to-left handling, and the background helpers (version check, session check).
- How an address gets its `{country}-{language}` prefix (`proxy.ts`), and how prices get the right currency per country.
- What search engines see (metadata, robots, sitemaps, structured data), the PWA manifest, and the monitoring tools: Sentry, PostHog, Google Analytics, Vercel Speed Insights. Security, secrets and the staging gate are in [`20-security-and-infrastructure.md`](./20-security-and-infrastructure.md).

## ⚠️ Works, with limits
- **L-1 — First-time visitors outside the served countries land on a blocking popup.** Default country is `gb`, and `gb` is not a market. The visitor first sees a fake progress bar of about 2–3 seconds (`PopupCountry.tsx:101-117`, random steps, not tied to loading). Then they must pick a country. The popup has no close button.
- **L-2 — Instagram's in-app browser is treated as a crawler.** The word `instagram` is in the bot list (`proxy.ts:79`), and Instagram's browser puts "Instagram" in its user agent. So a shopper who taps the bio link `/` gets a permanent 308 to `/gb-{lang}`. No geo, no saved country, and the region popup every time. The bot branch returns before the "gb → saved country" redirect (`proxy.ts:371-388` vs `:547`).
- **L-3 — The redirect-loop guard cannot fire in a real browser.** `proxy.ts` puts `x-redirect-count` on the redirect *response* (`proxy.ts:230-237`). A browser does not send response headers back on the next request, so `request.headers.get("x-redirect-count")` (`proxy.ts:496`) is always 0. The unit test sets the request header by hand, so it passes. The traced flows end on their own (the `changed-country` marker stops the bounce), so no loop was found.
- **L-4 — Right-to-left is done per component, not per page.** `dir` on `<html>` is commented out (`[lang]/layout.tsx:161`). The body gets the class `text-rtl`, but no CSS rule for `text-rtl` exists anywhere in the repo. The class does nothing. Each component sets `direction` itself (over 1,000 `isRtl` / `dir` references). A component that forgets it shows left-to-right in Arabic and Kurdish. `tests/app/layout.test.tsx` checks only that the class is present.
- **L-5 — hreflang language codes have no region.** Each of the 5 countries emits its own `en/ar/tr/ku` cluster (`buildAlternates.ts:21-27`), so Google sees 5 pages per language with the same code. Kurdish here is Sorani in Arabic script; the standard code for that is `ckb`, not `ku`.
- **L-6 — `gb` pages are in the sitemaps and are where crawlers land.** The sitemap index includes `gb-*` locales (`sitemap.service.ts:819`). A crawler with no locale is sent to `/gb-{lang}` (W-14). `Init.tsx` draws the region popup on any `gb-*` page and does not check for bots. So Google renders the home page with a full-screen popup over it.
- **L-7 — Sitemap limits.** The per-locale sitemap reads every product by scroll, with no 50,000 cap (`sitemap.service.ts:833-1016`, `:1122`). `sitemap-home.xml`, `sitemap-static.xml` and `sitemap-search.xml` are not linked from the index. No sitemap route checks the indexing flag. The locale sitemap logs its errors as "get currency error" (`[lang]/sitemap.xml/route.ts`).
- **L-8 — Structured data defects.** The Organization logo is `/icons/logo.svg` (`Organaization.tsx:11`), but the file is `public/icons/Logo.svg`. Vercel paths are case-sensitive, so the logo URL answers 404. The test expects the wrong path. The field is spelled `alternatename` (schema.org uses `alternateName`), and it lists 6 countries the app does not serve.
- **L-9 — Pages with no own metadata inherit "TryDos" and the global robots header.** 19 non-demo pages under `settings/` and `sellerProfile/` have no `generateMetadata`. When indexing turns on, these private pages say `index, follow`.
- **L-10 — Indexing flag change is slow on the home page.** The home metadata, including its robots value, is cached in Redis (`serverRequests/meta/home.ts:123`). After `NEXT_PUBLIC_ALLOW_INDEXING` changes, old values stay until the Redis TTL ends.
- **L-11 — Version bump logs every shopper out.** Changing `NEXT_PUBLIC_APP_VERSION` clears storage and all readable cookies, including `country` and `lang` (`version-manager.ts:43-68`). Every shopper is signed out and must pick a region again if they are outside a served country.
- **L-12 — Zoom is turned off.** `maximumScale: 1` and `userScalable: false` (`[lang]/layout.tsx:55-61`). Shoppers with weak eyesight cannot pinch to zoom.
- **L-13 — Monitoring gaps.** Sentry: no `tracesSampleRate` (no performance data), no `environment` in code, and `sendDefaultPii: true` on browser, server and edge. The client Sentry also runs in local development. The edge config does not strip the QA header. PostHog: session recording is off (`utils/posthog.ts`, `disable_session_recording: true`); it runs on every production build, so Vercel previews send data too; `posthogIdentify` sends the phone number. GA: every event has `debug_mode: true` (`utils/gtag.ts:57`, `:84`); if `NEXT_PUBLIC_GA_MEASUREMENT_ID` is missing, the script loads `?id=undefined`.
- **L-14 — Images are not optimised by Next.** `images.unoptimized: true` (`next.config.ts:218`). Sizes come only from Cloudinary transforms where `getConfiguredImage` is used. `images.domains` still lists `example.com`, `cdn.example.com`, `placehold.co` and two staging hosts.
- **L-15 — The NavLogo link goes to `/`** (`[lang]/layout.tsx:216`). Each tap is a full page load plus one redirect back to the locale.
- **L-16 — First render of client text may be English.** The client `translateFunction` loads the dictionary in the background and returns the English key until it arrives (`utils/functions.tsx:88-90`).
- **L-17 — PWA is install-only.** There is no service worker for offline use (only `firebase-messaging-sw.js` for push). `short_name` is "TRD". All icons are marked `maskable any`.
